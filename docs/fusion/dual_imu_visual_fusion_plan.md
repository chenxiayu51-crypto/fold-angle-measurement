# 折叠角度：双 IMU 与视觉融合方案

日期：2026-10-15。状态：设计建议；尚未取得 IMU 实测数据，也未实现或验证融合算法。

## 目标与已确认条件

- 闭合为 0°，完全展开为 180°；上下半机身各有一套三轴加速度计和三轴陀螺仪。
- 当前实验把下半机身、相机和铰链位置视为固定，补偿拍摄时的少量误移。
- 输出随时间更新的角度、相对角速度、估计不确定度和数据状态；视觉暂时缺失时仍能短时预测。
- 长期扩展允许整机运动。此时保留机械铰链约束，但取消固定图像交点假设。

“任意时刻可查询”指在最近一次观测基础上，用运动模型传播到查询时刻，并提供误差范围。传感器仍离散采样；不能通过插值获得没有观测支持的真实连续角度，也不能无限期保证精度。

## 方案选择

1. 推荐先做单自由度铰链滤波：状态为角度和相对陀螺零偏，计算量小，便于解释和对比当前固定装置的结果。
2. 两套完整姿态滤波后求相对姿态：适用于同时需要两半机身姿态的任务；独立六轴姿态估计会有航向漂移，仍需铰链约束和外部校正。
3. 滑动窗口优化：适合离线联合估计时间偏移、安装参数和角度轨迹；实现和计算成本更高，作为后续参考或标定工具。

第一版采用方案 1，先离线回放，再实时运行。

## 状态与观测

内部使用 rad、rad/s 和秒，输出时转换为度。定义：

`x = [theta, b_delta]`

`omega_rel = dot(h_upper, gyro_upper) - dot(h_lower, gyro_lower)`

`theta_next = theta + (omega_rel - b_delta) * dt`

`b_delta_next = b_delta + bias_random_walk`

其中两个 h 分别是在各自传感器坐标系内表示的单位铰链轴，必须指向一致的物理方向；标定符号使开启时 omega_rel 为正。轴一致后，整机绕铰链方向的公共转动才会在差分中抵消。不能直接相减两个同名 gyro 通道。

双 IMU 时间不一致时，先在统一时钟上插值或积分对齐相应角速度；不能把两个不同时间的样本当作同步值相减。协方差随传播增长，两个陀螺的噪声和零偏变化均需进入过程噪声。

第一版不另加独立角速度状态，角速度输出来自校正后的 omega_rel。若后续加入角加速度模型，应由实测数据判断是否改善延迟与噪声。

### 视觉校正

仅当视觉角度已通过几何标定可视为物理角度时，使用 `z_visual = theta + noise`。否则先采用投影观测模型 `z_visual = f(theta, camera_geometry) + noise`。

当前 `outputs/fold_angle_fixed/angles.csv` 的角度属于二维投影，尚不能直接作为机械角度真值。固定视角下，只有满足合适的侧视几何或完成平面校正后，才能将其作为物理角度观测。

建议使用有效帧的 `projected_angle_deg` 经几何校正后的值，保留检测质量和时间戳；该字段尚未经过时序平滑。`smoothed_projected_angle_deg` / `stabilized_projected_angle_deg` 用于显示，不默认作为新的独立观测，以免重复平滑、引入延迟及时间相关误差。

根据边缘支持长度、拟合残差、模糊和遮挡情况建立观测方差，再用独立数据校准这些质量指标与角度误差的关系。创新异常时拒绝观测；无效帧不填上次角度冒充测量。

视觉测量作用于曝光时刻。保存一段状态与 IMU 历史，在图像结果到达后回到对应时刻更新，再重放 IMU 传播到当前时刻。历史缓冲长度覆盖实际相机延迟和抖动；超出缓冲的旧观测应丢弃或进入离线处理。

### 加速度计校正

低动态时，从两半机身的重力方向以及已标定的铰链轴推导相对角度；使用重力在垂直铰链轴平面内的投影构造有符号角度，并通过机械零位标定映射到 0–180°。

当铰链轴接近重力方向时，投影接近零，重力对开合角度不可观，应显著减小权重或停止该项更新。加速度还含平移、切向及向心加速度；不能仅用加速度模长接近 g 来认定观测可靠。结合角速度、加速度变化和创新一致性判断。第一版先只在静止或缓慢运动片段使用该观测。

### 初值、端点和失效

初始绝对角度需要来自独立确认的机械位置、可靠视觉或可观测的重力关系。陀螺只能提供角度变化，不能单独确定初始开合角度。

独立确认到达机械闭合/展开止挡时，可以增加 0°/180° 观测；不要因估计值接近端点就强行当作真值。物理范围约束可以防止不合理输出，但不能消除漂移。静止时可更新陀螺零偏，需可靠静止检测。

视觉遮挡后继续 IMU 传播；重力可靠时继续校正。二者都不可用时，角度误差会随时间增长，输出应标记预测状态并增大不确定度。IMU 也中断时，只在限定短时间内按模型外推，之后标记过期。

## 同步采集约定

采样率先考虑 IMU 100–200 Hz、相机 30 Hz，最终依据设备能力、最快开合速度和延迟要求决定，以上并非当前硬件的已知参数。

原始 IMU 推荐长表，一行对应一个传感器事件，保留 acc 与 gyro 各自的采样时刻：

```csv
timestamp_ns,imu_id,stream,x,y,z,sequence,saturated
```

- `timestamp_ns`：采样时刻的整数纳秒时间戳；记录所属时钟域，避免用主机接收时间代替。
- `imu_id`：`upper` 或 `lower`；`stream`：`acc` 或 `gyro`。
- acc 单位 m/s²，gyro 单位 rad/s；记录原始坐标轴定义、轴向正负与传感器安装位置。
- `sequence` 和 `saturated` 用于识别丢样、重复及量程饱和；另存量程、标称频率、内部滤波配置和可用的温度信息。

视频帧日志：

```csv
frame_index,exposure_midpoint_timestamp_ns,clock_domain,exposure_duration_ns
```

优先硬件同步或统一采样时钟。独立时钟需要记录并估计时间偏移及频率漂移，可使用 `t_common = a * t_sensor + c`，同时保留原始时间戳。当前视频的帧序号/fps 仅是相对视频时间，不代表已与 IMU 同步。

单独保存标定文件：陀螺零偏/尺度、加速度偏置/尺度、各自铰链轴、开启方向、机械零位、相机内参与畸变/视角几何、时钟映射。参数需注明数据来源和适用安装状态。

融合输出建议：

```csv
timestamp_ns,angle_deg,angular_rate_deg_s,angle_std_deg,vision_used,gravity_used,status,last_imu_age_ms,last_visual_age_ms
```

`status` 区分已校正、仅传播、过期和未初始化。标准差是模型下的不确定度估计，需用独立误差数据检查一致性，不能直接宣称为精度保证。

## 实验顺序与验收

1. 采集同步的双 IMU、视频与独立角度参考。静止段用于偏置；多次开启/闭合用于铰链轴和符号检查。不能只用当前视觉角度自证融合精度。
2. 按多个已知角度静止保持，再做慢速、快速及停顿开合，检查 0–180° 定义、时间同步和动态延迟。
3. 固定开合角度后转动整个装置，检查共同运动是否抵消；加入视觉遮挡、丢帧、运动加速度，以及铰链轴接近重力方向的片段。
4. 离线使用同一批原始数据对比：仅陀螺积分、双 IMU 校正、视觉、双 IMU + 视觉。调参集与最终验证集分开。
5. 报告 MAE、RMSE、P95/最大角度误差、静止抖动、动态延迟、遮挡期间漂移、恢复时间和可用率；同时检查不确定度覆盖情况。精度和延迟指标需结合实际用途确定，目前没有实测验收结果。
6. 离线结果满足要求后，实现按时间戳接收异步数据的实时版本，并验证计算耗时、缓冲长度和长期时钟漂移。
