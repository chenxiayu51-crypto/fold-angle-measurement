## 单位与身份

- gyro 单位：`rad/s`（用户确认）。
- acc 单位：`m/s²`（由静止模长约 9.8 推断）。
- `加速度传感器`、`陀螺仪传感器`：主 IMU A（实验中固定）。
- `acc1`、`gyro1`：副 IMU B（实验中转动）。
- 身份映射由时钟分组和信号行为推断，不是硬件元数据。
